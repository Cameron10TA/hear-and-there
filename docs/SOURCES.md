# Content and asset sources

Sources checked October 13, 2026. Narrations are short original summaries of these sources, mixed with observation prompts. They are not recordings of students or real ambient sound.

## Styx

- Facts: [Whitman campus sculpture tour](https://www.whitman.edu/documents/global/Campus-Tours/Whitman-Sculpture-Tour.pdf), entry 22, describes Deborah Butterfield, 2002, bronze cast from driftwood, the Snake and Columbia rivers, and fabrication at the Walla Walla Foundry.
- Position: [OpenStreetMap node 12023094079](https://www.openstreetmap.org/node/12023094079), 46.0720452, -118.3290799. OpenStreetMap data is © OpenStreetMap contributors under ODbL; verify the GPS trigger on campus.
- Photograph: [Whitman campus-map photograph](https://www.whitman.edu/images/about/map/Map/55styxinautumn-ankeny.jpg). Downloaded unchanged; credit Whitman College. No open license is asserted.

## Outdoor tennis courts

- Location and description: [Whitman interactive campus map](https://www.whitman.edu/campus-map?plc=x37212). Located between Memorial Building and Maxey Hall. Coordinate chosen within the official map's outdoor-court polygon, 46.07137, -118.32851. The site says practices, classes, and students have priority.
- Photograph: [Whitman campus-map photograph](https://www.whitman.edu/images/about/map/Map/tennis.jpg). Downloaded unchanged; credit Whitman College. No open license is asserted.

## Design, map, and audio

- Colors: [Whitman brand guide](https://brand.whitman.edu/), blue #002868 and yellow #FFC627. This project uses a custom wordmark, Georgia/system fonts, and no official seal or restricted college logo.
- Map: [OpenStreetMap](https://www.openstreetmap.org/copyright), rendered with [Leaflet 1.9.4](https://leafletjs.com/). The Leaflet distribution and license are vendored locally.
- Sample narration: synthesized locally with the installed Microsoft Zira Desktop voice using Windows System.Speech; exported as mono PCM WAV at 22,050 Hz. Replace these with team recordings when ready. The transcript is in `src/landmarks.js`.
- Arrival sounds: original sine-wave chimes and bouncing tones generated by `src/audio.js`. These are sound design, not recordings of the actual locations.
- Icon: original SVG waveform created for this project.
